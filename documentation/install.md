# Install Maple Mono via Package Manager

Since Maple Mono V8 is still in development, the package manager versions may not be up to date. If you want the latest version, please download it from [Releases](https://github.com/subframe7536/maple-font/releases)

Or you can download [v7.9](https://github.com/subframe7536/maple-font/blob/v7/README.md#download)
